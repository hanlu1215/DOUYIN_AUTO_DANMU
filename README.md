# 抖音直播自动弹幕助手

Windows 下运行的抖音直播间自动发送弹幕工具。同一个工具提供 **三种实现**，功能完全一致，按需选用：

| 实现 | 目录 | 特点 |
|------|------|------|
| Python 版 | [PYTHON_SRC/](PYTHON_SRC/) | 纯标准库（tkinter + ctypes），无需 pip，改起来最方便 |
| C++ 版 | [WIN_C/](WIN_C/) | 原生 Win32 GUI + CMake，静态链接，单 exe 免依赖 |
| Rust 版 | [rust/](rust/) | 原生 Win32 GUI（windows-sys），cargo 构建，单 exe 免依赖 |

三个版本**共用**项目根目录下的 `danmu/`（弹幕文件）和 `config.json`（配置），可以混用。

## 功能

- **光标检测**：只有鼠标光标位于抖音直播间输入框区域内时才发送，移出即自动暂停，点回来自动继续
- **弹幕文件管理**：内容来自 `danmu/` 文件夹的 JSON 文件，界面下拉切换、导入新文件
- **频率控制**：基础间隔 + 随机抖动（±%），避免触发抖音「发言太快」限制
- **循环发送**：一轮发完后自动从头循环，每轮随机打乱顺序（默认开启）
- **自定义条目**：随时给当前 JSON 追加自定义弹幕（自动去重，立即生效）
- **防误发**：默认校验前台窗口标题包含「抖音」才发送，避免把弹幕打进其他程序
- **图形界面**：开始 / 停止、频率设置、区域框选、实时日志、发送统计

## 快速上手

1. 任选一个版本启动（见各目录 README）：
   - Python：`PYTHON_SRC/启动助手-静默.vbs`（无窗口）或 `python PYTHON_SRC/main.py`
   - C++：`WIN_C/build/douyin_danmu.exe`（构建见 [WIN_C/README.md](WIN_C/README.md)）
   - Rust：`rust/target/release/douyin_danmu.exe`（构建见 [rust/README.md](rust/README.md)）
2. 浏览器打开抖音直播间（网页版 `live.douyin.com`，或抖音 PC 客户端直播间）
3. 选择弹幕文件（内置 `danmu/陈伯夸夸.json`，2000 条）
4. 点击「**框选输入框区域**」，在抖音输入框上拖出一个矩形（Esc 取消）
5. 点击「**开始发送**」，把鼠标点进抖音直播间输入框 —— 自动开始发送
6. 光标移出输入框即暂停；点「■ 停止」结束

## 发言频率说明（重要）

抖音没有公开固定的弹幕间隔秒数，冷却时间是**动态计算**的：根据直播间人数、弹幕量、房间活动状态变化（见抖音专利 CN108551585B）；发言过快会收到「发言太快请你控制寄几」提示，严重刷屏可能被临时限制发言。

因此本工具：

- 默认间隔 **10 秒**（非常安全），界面下限 **2 秒**（无法调得更低）
- 默认开启 **每轮随机打乱**，并带 **±20% 随机抖动**，让节奏更接近真人
- 建议使用默认值，想要更活跃可适当调低间隔；切勿过度刷屏

## 弹幕文件格式

`danmu/` 文件夹中的 JSON 文件，字符串数组（每行一条）：

```json
[
  "陈伯，yyds！",
  "伯哥牛逼！",
  "陈伯大舞台，有梦你就来！"
]
```

也支持 `{"items": [...]}` 或 `{"danmu": [...]}` 格式。

## 项目结构

```
PYTHON_SRC/          Python 版（入口 main.py，含启动器 / 工具 / 自检）
WIN_C/               C++ 版（CMake 工程，src/ 源码，build/ 构建产物）
rust/                Rust 版（Cargo 工程）
danmu/               弹幕文件（三个版本共用，可自行添加 JSON）
config.json          配置（自动生成，三个版本共用）
error.log            无窗口启动时的崩溃日志（自动生成）
```

## 注意事项

- 发送时通过剪贴板粘贴文字（Ctrl+V），**发送期间你的剪贴板会被占用**，请勿同时复制其他内容
- 自动发送期间请勿自己在输入框打字，避免内容混在一起
- 自动发言存在账号被抖音风控的风险，请控制频率、谨慎使用，本工具仅供学习交流
- 若前台窗口标题不含「抖音」（如某些浏览器标签名不同），可在界面关闭该校验或修改关键词
- 无窗口方式启动时若程序闪退，查看项目根目录下的 `error.log` 获取报错信息
